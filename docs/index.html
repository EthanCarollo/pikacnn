🧠 PokéCNN

Reconnaître les 151 Pokémon de la première génération avec un réseau de neurones convolutif

🔍 Qu'est-ce qu'un CNN ?

Un Convolutional Neural Network (CNN) est un type de réseau de neurones spécialisé dans l'analyse d'images. Plutôt que de regarder l'image pixel par pixel, il applique des filtres (ou convolutions) qui détectent des motifs : bords, textures, formes… puis les combine couche après couche pour identifier l'objet final — ici, un Pokémon.

Le processus suit trois étapes :

  1. Convolution — des filtres 3×3 balayent l'image pour détecter des motifs.
  2. Pooling — on réduit la taille de l'image pour garder l'essentiel et accélérer les calculs.
  3. Dense — à la fin, des couches classiques prennent la décision finale.

🏗️ Architecture du modèle

Le modèle PokéCNN est construit avec JAX + Flax. Il prend une image RGB de 128×128 pixels en entrée et ressort une probabilité pour chaque Pokémon.

1
Conv2D 32 3×3 · BatchNorm · ReLU · MaxPool 2×2
↓
2
Conv2D 64 3×3 · BatchNorm · ReLU · MaxPool 2×2
↓
3
Conv2D 128 3×3 · BatchNorm · ReLU · MaxPool 2×2
↓
4
Conv2D 256 3×3 · BatchNorm · ReLU · MaxPool 2×2
↓
5
Conv2D 512 3×3 · BatchNorm · ReLU · MaxPool 2×2
↓
▸
Classifier Flatten → Dense 1024 → Dropout → Dense 151

Chaque bloc applique d'abord une normalisation par lot (BatchNorm) pour stabiliser l'apprentissage, puis ReLU pour la non-linéarité, et enfin un MaxPooling pour réduire la dimension spatiale. Le Dropout à 50% dans le classifier aide à éviter le surapprentissage.

📦 Dataset

Le modèle est entraîné sur les 151 Pokémon de première génération (Bulbizarre, Salamèche, Carapuce, Pikachu…). Le jeu de données est directement versionné dans le dépôt sous data/pokemon/ (images 128×128, un dossier par espèce) : il suffit de cloner le dépôt pour lancer l'entraînement, sans compte Kaggle. Il est recompilé par tools/build_dataset.py à partir de deux jeux de données publics Hugging Face (1stGen-Pokemon-Images de Dusduo et gen1-pokemon-images de RogerKoala), eux-mêmes basés sur le dataset Kaggle Pokemon Generation One.

Les données sont réparties en 70% entraînement, 15% validation et 15% test.

💻 Code source

Tout le code est sur GitHub.

Pour lancer l'entraînement :

pip install -r requirements.txt
python train.py

Optimiseur : AdamW avec cosine decay et warmup. Early stopping avec patience de 10 époques. Checkpoint automatique du meilleur modèle.
